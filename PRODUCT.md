# GPUI Lab
<!-- impeccable:product-schema 1 -->

## Platform
Native macOS desktop prototype.

## Stack
Rust with the actual GPUI framework, as implied by the user's request to demonstrate GPUI.

## Users and purpose
The user wants to understand GPUI and try its distinctive capabilities. The user explicitly selected a graphics and performance playground.

## Capabilities and constraints
Demonstrate GPU-painted animated primitives, a virtualized 100,000-row list, reactive application state, and keyboard actions. Measurements must come from the running application; synthetic data is explicitly labeled. Avoid claiming that these capabilities are exclusive to GPUI or a substitute for controlled comparative benchmarking.

## Evidence
Official gpui.rs documentation, published gpui 0.2.2 source and examples. Existing unrelated web experiments are outside this prototype's scope.
